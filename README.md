# Hello, Face!

Faces hiding in clouds, leaves, anything.

- **Cloud Camera** — https://kidapu.github.io/Hello-Face/cloud/
  Point your phone at the sky and cat / bear doodles appear on the clouds.
  Tap a face to change the animal, long-press to change the expression.

## Layout

- `lib/doodle.js` — draws the hand-drawn cat / bear faces (Canvas 2D)
- `lib/cloudfind.js` — finds the round bulges of clouds in an image
- `cloud/` — camera web app
