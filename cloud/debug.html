雲の動物 デバッグ

それぞれの顔に ID が付いています（例 cat/smile）。「bear/happy の目をもう少し大きく」のように ID で指示してもらえると、どの顔の話かがはっきりします。すぐ下のつまみは全部の動物に共通の設定です。動物ごとのカードにある「○○だけの調整」を開くと、その動物だけを変えられます。ここで変えた設定は、同じブラウザで開いたカメラにも反映されます。

雲 1 つごとに、形の特徴（細長さ・大きさ・曲がりなど）を測り、上から順にルールを確かめます。条件が全部合った最初のルールの動物になります。しきい値のつまみを動かすと、③ の写真の結果にもすぐ反映されます。

指示の出し方の例

  • 顔：「cat/pokan の口をもっと小さく」「sheep 全部、ほっぺを濃く」「fish/smile の目を丸く」
  • ルール：「ルール R5 bear の細長さ 1.6 を 1.8 に」「clouds18.jpg の顔 #3 はヘビじゃなくてイルカにしたい」
  • 写真：③ で写真を選んで顔をクリックし、出てきた理由のカードをスクリーンショットで送ってもらうのが一番早いです。

変えた設定（そのまま貼り付けて送れます）

① と ② のつまみで、初期値から変えたものだけを書き出します。
